AI Chatbot

**AI_ChatBot_Project01** is an AI-powered conversational chatbot developed using Python, Natural Language Processing (NLP), and Machine Learning. The system uses NLTK for text preprocessing, a Bag-of-Words model for feature representation, and a TensorFlow/Keras neural network to identify user intents and generate appropriate responses. User messages are tokenized and lemmatized before being converted into numerical features, which are then processed by the trained model to determine the most relevant intent. Responses are selected from a predefined set of intents and conversational patterns stored in a JSON dataset. The project demonstrates fundamental concepts of NLP, text classification, neural networks, model training, and AI-based human-computer interaction. Designed primarily for educational purposes, it provides a practical foundation for understanding how intelligent chatbots are developed and can be further enhanced with advanced NLP techniques, word embeddings, LSTM or Transformer models, and web-based interfaces.

05

Deep Learning Project

Rice Disease Classification

**Rice Disease Classification** is a deep learning project developed to automatically identify and classify rice plant diseases from leaf images. The project uses a Convolutional Neural Network (CNN) implemented with TensorFlow and Keras to classify images into 10 different categories, including bacterial diseases, blast, brown spot, dead heart, downy mildew, hispa, tungro, and healthy leaves. The dataset contains 10,407 images covering multiple rice varieties and plant growth stages. The project includes exploratory data analysis, image preprocessing, CNN model development, training, and performance evaluation using accuracy and loss metrics. The model achieved approximately 99% training accuracy and 79.8% validation accuracy. Developed for academic and research purposes, the project demonstrates the practical application of computer vision and deep learning in agricultural disease detection and provides a foundation for future deployment in web or mobile-based crop diagnostic systems.

Python TensorFlow Keras Convolutional Neural Network (CNN) Image Classification Deep Learning
GitHub - Rice Disease Classification
