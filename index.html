C project

Parking Lot Management System

The **Parking Lot Management System** is a C-based console application developed to streamline and organize essential parking lot operations. The system provides comprehensive functionality for administrator management, vehicle and owner registration, parking space allocation, vehicle entry and exit management, automated parking fee calculation, and report generation. It supports up to 50 parking spaces and uses file-based data storage to maintain records persistently. The application incorporates input validation, parking occupancy monitoring, vehicle status tracking, and structured reporting to ensure efficient management of parking resources. From a technical perspective, the project demonstrates practical applications of fundamental C programming concepts, including structures, arrays, functions, file handling, string manipulation, and time management. Developed as an academic project, the system provides a practical foundation for understanding real-world management software while strengthening programming, data management, and problem-solving skills. Future enhancements may include database integration, a graphical user interface, online payment, digital parking tickets, license plate recognition, and cloud-based data management.

02

Python Project

AI Chatbot

**AI_ChatBot_Project01** is an AI-powered conversational chatbot developed using Python, Natural Language Processing (NLP), and Machine Learning. The system uses NLTK for text preprocessing, a Bag-of-Words model for feature representation, and a TensorFlow/Keras neural network to identify user intents and generate appropriate responses. User messages are tokenized and lemmatized before being converted into numerical features, which are then processed by the trained model to determine the most relevant intent. Responses are selected from a predefined set of intents and conversational patterns stored in a JSON dataset. The project demonstrates fundamental concepts of NLP, text classification, neural networks, model training, and AI-based human-computer interaction. Designed primarily for educational purposes, it provides a practical foundation for understanding how intelligent chatbots are developed and can be further enhanced with advanced NLP techniques, word embeddings, LSTM or Transformer models, and web-based interfaces.

Python Project

Headline Generator

**Headline Generator** is a Python-based command-line application that generates creative and humorous news-style headlines using randomized combinations of predefined subjects, actions, and places or things. The project uses Python’s built-in `random` module to select different elements and dynamically combine them into unique headlines. It provides a simple interactive interface that allows users to generate multiple headlines continuously until they choose to exit. The project demonstrates fundamental Python programming concepts, including lists, loops, user input, random selection, string formatting, and basic program flow control. Developed as a beginner-friendly project, it provides practical experience in building interactive console applications while demonstrating how simple programming techniques can be used to create dynamic text generation systems. Future enhancements could include custom user inputs, categorized headline generation, file-based storage, and a graphical user interface.
