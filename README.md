# 💼 Personal Portfolio

A modern and responsive personal portfolio website designed to showcase my **skills, projects, education, experience, and professional profile** in a clean and organized way.

## ✨ Features

* 🏠 Professional introduction and hero section
* 👩‍💻 About Me section
* 🛠️ Skills and technologies showcase
* 🚀 Featured projects
* 🎓 Education information
* 📄 Resume/CV section
* 📬 Contact information
* 🔗 Social media and professional links
* 📱 Responsive design for desktop, tablet, and mobile devices
* ✨ Clean and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling and responsive layout
* **JavaScript** — Interactivity and dynamic functionality

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Jtithy/Portfolio.git
```

### 2. Navigate to the Project

```bash
cd Portfolio
```

### 3. Run the Website

Open `index.html` directly in your browser.

For development, you can also use **VS Code Live Server** to preview the website locally.

## 🎯 Purpose

This portfolio serves as a centralized platform to present my academic background, technical skills, projects, and development experience. It is designed to provide recruiters, collaborators, and visitors with an overview of my work and capabilities.
